# 🦉 AksharaFlow Studio
**Every Script. Every Finger. Free Forever.**

**AksharaFlow Studio** is a 100% free, open-source, offline desktop touch-typing coach and arcade game studio for **English (QWERTY)** and **13 Indian Language Scripts (Govt. of India Standard InScript)**.

---

## ✨ Key Features

- **Zero-Password Local Profiles:** Simply enter your name, pick your script, and your lessons, WPM history, streak, and weak-key diagnostics resume automatically.
- **14 Supported Language Scripts (237 Progressive Lessons):**
  1. **English** (`QWERTY Standard` — 29 Lessons across 8 Units)
  2. **Hindi** (`हिन्दी` — Devanagari InScript)
  3. **Marathi** (`मराठी` — Devanagari InScript)
  4. **Sanskrit** (`संस्कृतम्` — Devanagari InScript)
  5. **Bengali** (`বাংলা` — Bengali InScript)
  6. **Punjabi** (`ਪੰਜਾਬੀ` — Gurmukhi InScript)
  7. **Gujarati** (`ગુજરાતી` — Gujarati InScript)
  8. **Odia** (`ଓଡ଼ିଆ` — Odia InScript)
  9. **Tamil** (`தமிழ்` — Tamil InScript)
  10. **Telugu** (`తెలుగు` — Telugu InScript)
  11. **Kannada** (`ಕನ್ನಡ` — Kannada InScript)
  12. **Malayalam** (`മലയാളം` — Malayalam InScript)
  13. **Assamese** (`অসমীয়া` — Assamese InScript)
  14. **Urdu** (`اردو` — Standard / InScript)
- **Dual-Mode InScript Engine:**
  - Includes native-language instructions showing how to enable your Windows InScript keyboard (`Win + Space`).
  - Also includes a **Built-in Smart Auto-InScript Mapper** that automatically maps physical QWERTY keys to InScript characters even when your OS keyboard is still set to English.
- **Coach Kavi's Adaptive Mistake Clinic:**
  - Tracks per-key error rates, reaction latency (ms), key confusion pairs, and per-finger accuracy.
  - Dynamically generates personalized weak-key remedial workouts in your active script.
- **3 Multi-Script 60–144fps HTML5 Canvas Arcade Games:**
  - **🫧 Bubble Pop Reflex:** Pop rising bubbles in your chosen script, featuring Golden Boss Bubbles that train your weakest keys.
  - **☄️ Meteor Laser Defense:** Lock your plasma turret onto falling words and shatter meteors mid-air.
  - **🏎️ Nitro Type Sprint:** Type full punctuated sentences to boost your roadster past 3 WPM-calibrated pace cars.

## 🚀 Download & Run

### Option 1: Standalone Windows Executable (`.exe`)
Double-click **`dist/AksharaFlow_Studio.exe`** — no Python installation or internet connection required!
All learner progress is safely stored in `%LOCALAPPDATA%\AksharaFlowStudio\aksharaflow_studio.db`.

### Option 2: Run from Source (Python 3.9+)
```bash
python backend/app.py
```

### Rebuilding the `.exe`
```bash
build_exe.bat
```
